# Awesome Design MD — Brand Design Reference Library

A curated collection of **74 real brand design systems**, each captured as a
single `DESIGN.md` file with YAML front-matter (tokens) + prose (rationale,
do's/don'ts, responsive rules).

## When to use

- Choosing a visual identity or refining an existing one.
- Picking a color palette, type scale, spacing system, or radius scale grounded
  in a system that actually ships.
- A UI should evoke a known brand ("make it feel like Linear / Apple / Stripe").
- Cross-checking your design decisions against a reference (elevation, tracking,
  whitespace philosophy).

## How to use

1. Pick the closest reference brand for the desired feel. Browse:
   `.claude/skills/awesome-design-md/design-md/<brand>/DESIGN.md`
2. Read its front-matter for the exact tokens (`colors`, `typography`,
   `spacing`, `rounded`, `components`) and the prose for **Principles** and
   **Do's and Don'ts**.
3. Borrow the *discipline* (surface ladder, tracking, focus rings, rhythm) —
   adapt tokens to the project's own palette rather than copying wholesale.
